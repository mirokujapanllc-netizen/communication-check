# 社長の伝達ロス診断（BtoE式）

「あなたの伝え方のクセ社長図鑑」の6タイプ診断アプリです。
24の質問にチェックすると、6タイプ（正論武将・ロジカル博士・期待の鬼コーチ・
優しすぎる調整役・自由なアイデアマン・マイペース探求者）のうち、
最も当てはまるタイプが判定され、NGワード→OK変換表が表示されます。

- React + TypeScript + Tailwind CSS
- ログイン不要・データ保存不要・外部API不要（ブラウザだけで完結）
- スマホファースト・レスポンシブ対応
- 「結果を画像として保存」機能は外部ライブラリを使わず、ブラウザ標準のCanvas APIのみで実装

すべてのロジック・UIは `src/App.tsx` の1ファイルにまとまっています。

最初に性別（男性／女性）を選んでもらい、6タイプ×男女で結果イラストを出し分けます。

## キャラクター画像について

`public/characters/male/` と `public/characters/female/` の各フォルダに、指定のファイル名
（`shogun.png` など）で画像を置くと、結果画面・シェア画像の両方に自動的に反映されます。
詳しくは `public/characters/README.txt` を参照してください。画像がまだ無い間は、
代わりにタイプごとの色付きアイコン（番号入り）が自動で表示されます。

## ローカルで動かす

```bash
npm install
npm run dev
```

## Vercelへデプロイする

これまでと同じ手順です。

1. このフォルダをGitHubに新しいリポジトリとしてアップロード
2. [vercel.com](https://vercel.com) で「Add New → Project」→ このリポジトリを選択
3. Framework Presetが自動で **Vite** になっていることを確認
4. **Root Directory** を、フォルダをアップロードした場所に合わせて設定
5. 「Deploy」をクリック

## カスタマイズ

`src/App.tsx` 内の以下の定数を、実際のURLに差し替えてください。

- `NOTE_URL`：根本改善の有料noteへのリンク
- `COMMUNITY_URL`：社長同士がつながるコミュニティ・LINEへのリンク

## ビルド確認

```bash
npm run build
```

型エラーなし・ビルド成功を確認済みです。
